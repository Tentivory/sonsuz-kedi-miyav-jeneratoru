# Sonsuz Kedi Miyav Jeneratörü

**DİKKAT: Bu repo ciddidir. Ciddiyet seviyesi %1000'dür. Mizah yasaktır. (Yalan.)**

## Ne Bu Lan?

Bu proje, insanlığın en büyük sorunlarından birini çözmek için yaratılmıştır: *Yeterince kedi miyavı üretmek.*

Evet, doğru okudunuz. Artık evinizde kedi olmasa bile, sonsuz miktarda miyav üretebilirsiniz. Bilim bunu bekliyordu. Bilim şimdi ağlıyor.

### Özellikler (Abartılı)

- Rastgele uzunlukta miyavlar üretir (1 ile 42 arası, çünkü 42 hayatin cevabıdır).
- Her miyavın "derin anlamını" yorumlar (yoktur).
- Çalışır. Gerçekten çalışır. Test ettik, kediler bile onayladı.
- Hiçbir şey yapmaz aslında, ama yapıyormuş gibi yapar. Mükemmel.

## Kullanım

